# Движок агентского цикла

Живой документ о конвейере разработки на агентах: из каких частей он состоит, как они связаны, где работают агенты, где скрипты и где решает человек. Модель описана как код на [LikeC4](https://likec4.dev): по одной модели строятся все картинки, от общей к деталям.

Черновик v0, гипотеза. У каждой части есть статус: `built` — есть сейчас, `planned` — решено строить, `idea` — только идея.

## Как смотреть

```bash
npm install
npm run dev     # сайт с горячей перезагрузкой
npm run check   # проверка модели
npm run build   # один HTML-файл в dist/
```

## Устройство

- `model/spec.c4` — типы частей и связей: агент, скрипт, ворота, человек, хранилище, фаза; статусы.
- `model/engine.c4` — сами части и связи между ними.
- `model/views.c4` — картинки:
  - `0. Весь цикл` — восемь фаз слева направо, Оператор сверху;
  - `1–8` — по картинке на фазу, клик по фазе на общей картине открывает её;
  - `9. Сквозные части` — оркестратор, песочница, трассы;
  - `10. Что есть, что в планах` — статусы всех частей;
  - `11. Сценарий: фича` — путь задачи с ветвлением по классу риска, циклом ревью и параллельными ревьюерами.
- `GLOSSARY.md` — термины: фазы по SDLC, кто делает работу, статусы, понятия.

Доказательства к частям лежат в атласе (`stage` в метаданных = номер области атласа).
