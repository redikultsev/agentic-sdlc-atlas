## Key question: is there any measurement that a code map, walkthrough or summary makes HUMAN decisions faster or more correct?

Every number found:

1. **Copilot for PRs (AI-written PR summary)**: −19.3 h review time, 1.57× merge likelihood (observational, FSE 2024). The closest to "summary → faster decision", but no correctness measure and self-selected adopters.
2. **PR message-code inconsistency**: wrong summary ↔ 3.5× slower merge (55.8 h vs 16.0 h), acceptance 28.3% vs 80.0% (observational). Evidence that a *bad* summary costs time; not that a good one saves it.
3. **PR description structure (2602.17084)**: structured descriptions associated with faster completion (effect size ε²=0.325 for time across agents, confounded by agent).
4. **Trust-Calibrated Code Review**: 63% *expect* less review effort, 52% less trust-assessment effort (survey of a prototype, not a measured outcome).
5. **Habituation at the Gate**: the opposite direction: over time humans approve agent PRs +14.5 pp more with 22% fewer comments; scrutiny drops without any tool.
6. **Anthropic RCT (via Osmani)**: AI-assisted learners scored 17% lower on comprehension at equal speed. About comprehension loss, not about maps.
7. **CodeGraph**: 53% faster / 88% fewer tool calls, but for an **agent**, not a human.
8. **CodeWiki**: doc quality 82.23 vs DeepWiki 65.06 by LLM-judge rubric, not human outcome.

**Answer: no.** None of the 21 candidates, and none of the three extra studies, contains a controlled measurement showing that a code map, guided walkthrough, layered PR tour or wiki makes a human's decision faster *and* more correct. Tools (Floorplan, Understand Anything, Archify, DeepWiki, Code Wiki, CodeRabbit, Linear, Devin Review, Plannotator, Antigravity, GitHub stacks) offer zero numbers about human outcomes. The only "faster" numbers for humans are observational associations with PR summaries (Copilot for PRs; message-code inconsistency). The best-measured study (Habituation) shows the risk side: human review gets shallower. This is an empty niche for a timed, correctness-scored experiment.
