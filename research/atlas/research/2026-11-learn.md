# Learning from mistakes in an agent pipeline

Research of 2026-11-20, three parallel searches: how corrections become rules, where a rule lives and how rules stay few, which metrics teams track and whether anyone automates the retro. All web access through the fetchira router (serper).

## Answer

1. Human corrections are the signal everyone uses: review comments, bugs, repeated corrections (OpenAI, Anthropic, CodeRabbit, Greptile, Devin, Copilot). Anthropic's own threshold is "the same mistake twice".
2. Nobody runs a separate "adopt rule?" gate. OpenAI's recurring background tasks open fix-up PRs and the PR is the approval; tools that learn on every comment drop bad lessons by expiry or acceptance rate instead of approving each one.
3. A lesson that must always hold goes into a linter, test or hook, with an error message that says how to fix it; prose in the instruction file only for guidance the agent may judge not to apply. "When documentation falls short, we promote the rule into code" (OpenAI); "never send an LLM to do a linter's job" (HumanLayer).
4. Instruction files stay short (OpenAI ~100 lines as a map, Anthropic under 200, HumanLayer under 60) because following degrades with the number of instructions (IFScale: the best model 68% at 500) and with context length (Chroma). One study found context files raised cost by over 20% without raising task success. Rules that do not pay off get removed.
5. Security bodies say to treat instruction files as code: CODEOWNERS and review. No source excludes them from auto-merge; OpenAI auto-merges its cleanup PRs.
6. Metrics are a funnel: PRs merged and how fast, how often a person steps in, reverts and incidents, cost per merged PR. PR volume rises while delivery stays flat unless review keeps pace (Faros, DORA). Published cadences are dashboards over 28–60 days; no source for a weekly pushed report.
7. Pitfalls of self-improving loops: rule bloat, details eroding when a model rewrites its own context, reward hacking (o3 changed tests or graders in 30.4% of RE-Bench runs, METR), scope creep, Goodhart.
