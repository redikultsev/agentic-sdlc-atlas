# X6. Economics

Phase F1 broad sweep, 2026-11. Not yet verified in depth: `search-snippet` rows were not opened.

## State of the art

By late 2026 the economics of agentic development has a common vocabulary: cost per merged PR (or cost per solve) is replacing cost per token as the unit that matters, because token counts, invoices and list prices all mislead. Measured evidence agrees on four points. Agent runs are highly variable, up to 30x on the same task. Input and cache reads dominate the bill, not output. Returns diminish fast past roughly the first million tokens per user per month. Human review, not inference, is the binding constraint: two large econometric studies and several analytics vendors find that commits jump while releases and resolved issues rise only 13-30%. Routing by step (cheap executor with a frontier advisor or coordinator, risk tiers for review) has solid production evidence at Cloudflare and Anthropic, but vendors also document routing savings being eaten by rework. Subscription vs API is in flux: Anthropic split programmatic usage into separate credits and banned third-party harnesses on subscriptions, GitHub moved Copilot to token billing, and enterprises (Uber, Salesforce, Tesla, Walmart, Accenture) added hard per-person caps in 2026. ROI is still mostly self-reported. METR's own RCT redesign shows that measuring speedup has become methodologically hard.

## Approaches

| Approach | What | Evidence | Seen in |
|---|---|---|---|
| **Cost per merged PR / cost per solve as the unit metric** | Divide total AI spend (tokens, sometimes seats, CI and review time) by merged PRs that survive, or by tasks that pass tests, instead of tracking tokens or invoices. | mixed | CampusIQ $29 per merged PR, Requesty open-weight cost-per-solve benchmark, Jellyfish State of AI H1 2026, Unblocked cost-per-merged-PR / token yield, Token Reduction Is Not Cost Reduction (arXiv 2607.12161) |
| **Per-step model tiering (advisor/executor, coordinator/specialists)** | Run a cheap model for most of the work and call a frontier model only for hard decisions, coordination or the final judgment. | strong | Anthropic advisor tool, Cloudflare AI code review, Aider architect/editor, claude-code-router, Claude Code cost docs (Sonnet teammates, Haiku subagents) |
| **Risk-tiered verification spend** | Scale review/verify effort to the size and sensitivity of the diff, for example 2 agents on trivial MRs, 7+ on large or security-touching ones, and a cheaper coordinator on the trivial tier. | strong | Cloudflare AI code review, LinearB AI code review bottleneck (auto-approve tiny/safe changes) |
| **Router by task classification (single up-front dispatch) vs cascade** | Classify a task up front and send it to the cheapest capable model, or try the cheap model first and escalate on failure. Rework from mis-routes can erase the savings. | mixed | Unblocked model routing analysis, RouteLLM (cited), Joint Plan-Time Model Routing (arXiv 2609.32917) |
| **Hard budget caps and gateways** | Per-user, per-team, per-key or per-run spend limits enforced at an LLM gateway or in the agent (--max-budget-usd), with alerts before the limit. Budget alerts alone are not a kill switch. | mixed | LangChain LangSmith LLM Gateway, Claude Code cost docs, Enterprise caps (Uber/Salesforce/Tesla/Walmart/Accenture), ccusage, Runaway-bill incidents compilation (YSecurity) |
| **Harness/context efficiency instead of a cheaper model** | Cut cost per task with skills, structured context, cache hit rate, shared context files and fewer redundant reads and test re-runs. Effects on total cost are not obvious: compression can raise the bill. | strong | Analyzing and Mitigating Cost-Inefficient Behaviors (arXiv 2609.30725), Token Reduction Is Not Cost Reduction (arXiv 2607.12161), Cloudflare AI code review, Jellyfish State of AI H1 2026 |
| **Subscription arbitrage vs metered API** | Flat subscriptions (Max/Ultra, Copilot seats) hide marginal cost and are subsidized, but limits, harness bans and the move to metered credits are shrinking the arbitrage. | mixed | Anthropic programmatic/Agent SDK credits, Anthropic third-party harness ban, GitHub Copilot usage-based billing, Cursor June 2025 pricing change, Pragmatic Engineer 27-company AI spend survey |
| **Open-weight models for cost floor** | Swap frontier models for hosted open-weight models (DeepSeek, GLM, Kimi) on lower-risk steps. Provider price variance and lower success rates on hard tasks change the math. | mixed | Requesty open-weight cost-per-solve benchmark, Cloudflare AI code review (Kimi on Workers AI) |
| **Measuring ROI at the shipped-output level** | Econometric or telemetry studies that follow AI effects from commits to PRs to releases and resolved issues, and find that human bottlenecks (review) attenuate the gains. | strong | NBER w35275 Writing Code vs Shipping Code, Chen & Stratton, AI in the Firm (Harvard/Jellyfish), METR RCT and 2026 redesign, Faros AI Productivity Paradox / Acceleration Whiplash, LinearB 2026 Benchmarks |

## Open gaps

- No public, fully loaded cost per merged change (tokens plus CI plus sandbox plus human review minutes plus rework) from any organization. CampusIQ and Cloudflare publish token-only or review-only figures.
- No independent measurement of how much quality cheap verifier or reviewer models lose against frontier ones, or of how many defects reach production when the review step is downgraded.
- How much human review time an agent PR costs in minutes, broken down by PR size and risk, and how that changes with auto-approval policies. Studies report waiting time, not effort.
- Solo or small-team economics of running 10+ concurrent agents: where the attention ceiling (Jellyfish's 84% at 1-2 agents) actually binds, and the marginal cost per extra agent.
- Whether advisor or executor routing savings hold on real repos (not SWE-bench or BrowseComp) and on long-horizon tasks. Only vendor numbers exist.
- Real subscription-vs-API break-even for headless and orchestrated workloads after the June 2026 programmatic-credit split. Only blog arithmetic exists, no measured multi-agent comparison.
- How much of the bill silent prompt-cache misses cause in proxy or router stacks. Only isolated incident reports exist.
