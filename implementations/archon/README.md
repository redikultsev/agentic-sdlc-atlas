# agentic-pipeline: the Archon implementation

The pipeline described in `../../model/`, `../../docs/decisions.md` and `../../docs/states.md`, built as an Archon workflow pack. The plan and the order of work: `../../docs/build-plan.md`.

Install on an Archon server: `archon plugin add redikultsev/agentic-sdlc-atlas/implementations/archon@archon-pack-vX.Y.Z`; update with `archon plugin update`. Workflows run as `redikultsev/agentic-pipeline:<workflow>`. Check: `archon workflow run redikultsev/agentic-pipeline:pipeline-ping`.
